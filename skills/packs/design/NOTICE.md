# Design pack — sources and licenses

Nothing in this pack is copied from another project. The pack names the sources below because its procedure or its
guidance follows them.

## design.taste — procedure reference

The shape of the taste procedure follows **skeltonmedia/design-taste-skills** (https://github.com/skeltonmedia/design-taste-skills),
MIT, read at commit e0c84740c3f8388160f8dfcca366035e83243adb (2026-10-20): taste as recorded judgement, an interview over
references, a rejection log with reasons, promotion only of signals that recur (there: three times across different
sessions), and inferences marked as such. No text, file or code was copied. The strata version is written anew: one note
per project or brand instead of per person, three different briefs as the promotion threshold, an expression note with
computed relations, `python3 -m kb taste` checks, six locales (DEC-2026-11-01-10 · 11).

design.brief may suggest, at its make step, a design skill the person already has installed (DEC-2026-11-01-12). The pack

## design.brief — category adapters

`design.brief/data/adapters.md` condenses the person's own document "디자인 스킬: 공통 코어와 카테고리 어댑터"
(claude.ai, 2026-11-01). The rules in it are common craft references (pyramid principle, action titles, WCAG 2.2 AA
contrast, platform touch-target sizes); no third-party text is copied (DEC-2026-11-01-13).

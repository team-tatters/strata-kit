# strata.translate

## 개요

카드·스킬 본문·역할 텍스트·문서의 빠진 로케일을 정본 텍스트와 용어집에서 채웁니다. 의미, 식별자, 구조는 바꾸지 않습니다.

## 언제 쓰는가

i18n 검사가 미번역 로케일을 보고할 때, 새 텍스트를 쓴 뒤, 요청이 있을 때 씁니다. 의미를 번역하고 식별자는 절대 번역하지 않습니다.

## 절차

1. tools/i18n_check.py 를 돌려 미번역 항목을 나열합니다. 증거: 출력.
2. 용어집과 정본 텍스트를 읽습니다. 증거: 경로.
3. 빠진 로케일을 씁니다. 식별자·enum·키·플레이스홀더는 동일하게, 스킬 본문은 절 순서를 유지합니다. 증거: diff.
4. 검사를 다시 돌립니다. 오류 0, 경고는 줄어야 합니다. 증거: 출력.
5. 정본이 모호한 문장은 작성자에게 보낼 질문과 함께 표시합니다.

## 합리화

| 생각 | 반박 |
|---|---|
| "대충 번역해도 없는 것보다 낫다." | 대충 번역한 규칙은 다른 규칙입니다. 정확히 번역하거나 표시하세요. |
| "식별자가 대상 언어로 어색하니 현지화하겠다." | 식별자는 정책상 영어입니다. 라벨을 현지화하고 id 는 두세요. |
| "플레이스홀더는 옮겨도 된다." | 플레이스홀더는 정확히 일치해야 합니다. 아니면 생성기가 깨집니다. |

## 적신호

- 번역된 enum 이나 키.
- 문장이 더 있거나 빠진 로케일.
- 줄지 않은 검사 경고.

## 검증

- 식별자가 동일하다.
- 검사 오류 0, 경고 감소.
- 모호한 곳을 표시했다.

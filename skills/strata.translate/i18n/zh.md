# strata.translate

## 概述

依据规范文本并使用术语表，补全建议卡片、技能正文、角色和文档中缺失的语言环境，且不改变含义、标识符或结构。

## 适用场景

i18n 检查报告有待处理的语言环境时、新文本撰写之后，或应要求时。翻译含义；绝不翻译标识符。

## 流程

1. 运行 tools/i18n_check.py 并列出待处理项。证据：输出。
2. 阅读术语表和规范文本。证据：路径。
3. 写出每个缺失的语言环境，保持标识符、枚举、键和占位符完全一致；技能正文中保持章节顺序。证据：diff。
4. 重新运行检查；错误必须为零，警告必须减少。证据：输出。
5. 标出规范文本含糊的任何句子，并附给作者的问题。

## 借口与反驳

| 想法 | 反驳 |
|---|---|
| “粗略的翻译也比没有强。” | 粗略的规则就是另一条规则。要么精确翻译，要么标出。 |
| “标识符在目标语言里不顺口，我来本地化它。” | 按政策标识符一律用英文。本地化标签，而不是 id。 |
| “占位符可以挪位置。” | 占位符必须完全匹配，否则生成器会出错。 |

## 警示信号

- 被翻译的枚举或键。
- 某个语言环境多出或少了一句。
- 警告没有减少。

## 验证

- 标识符一致。
- 检查错误为零，警告减少。
- 含糊之处已标出。

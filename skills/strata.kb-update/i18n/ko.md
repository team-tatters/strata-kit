# strata.kb-update

## 개요

as-built 지식을 코드와 같게 유지합니다. 바뀐 경로마다 소유 문서를 찾아 출처와 함께 제자리 갱신하거나 왜 갱신이 필요 없는지를 기록하고, 생성 뷰를 다시 만듭니다.

## 언제 쓰는가

covers 가 맡은 코드가 바뀐 뒤, 게이트나 부채 알림이 울렸을 때, 요청이 있을 때 씁니다. 이유와 함께 doc_change: none 을 선언하는 것도 유효한 결과입니다.

## 절차

1. 바뀐 파일을 나열하고 covers 로 소유 문서를 찾습니다. 증거: 대응표.
2. 소유 문서마다 해당 절을 제자리 갱신하고 updated 와 sources 를 적습니다. 증거: diff.
3. 소유자가 없는 경로는 형상 문서를 만들거나 covers 를 넓힙니다. 증거: 새 대응.
4. 형상이 바뀌지 않았으면 이유와 함께 doc_change: none 을 적습니다. 증거: 선언.
5. 색인을 다시 만들고 링크 검사를 돌립니다. 증거: 출력.

## 합리화

| 생각 | 반박 |
|---|---|
| "내부 변경이라 문서는 영향 없다." | 그러면 그 이유로 doc_change: none 을 선언하세요. 게이트는 가정이 아니라 선언을 봅니다. |
| "다음 세션에서 문서를 고치겠다." | 다음 세션은 무엇이 바뀌었는지 모릅니다. 지금 고치거나 선언하세요. |
| "날짜만 갱신하면 된다." | 내용 검토 없는 날짜는 날짜 붙은 drift 입니다. |

## 적신호

- 갱신도 선언도 없는 바뀐 경로.
- 출처 없이 갱신된 문서.
- 손으로 다시 만든 노드 페이지.

## 검증

- 대응표가 완전하다.
- 색인과 링크 검사가 통과했다.
- 선언에 이유가 있다.

# strata.kb-update

## 概述

让现状形态知识与代码保持一致：为每个变更路径找到负责它的文档，就地更新并附上来源，或记录为什么无需改动，然后重新生成生成视图。

## 适用场景

被覆盖的代码改动之后；关卡或债务通知触发时；应要求时。也用于声明 doc_change: none 并附理由，这是有效的结果。

## 流程

1. 列出变更文件，并通过 covers 找到它们所属的文档。证据：映射关系。
2. 对每个所属文档：就地更新相关章节；设置 updated 和 sources。证据：diff。
3. 对没有所属文档的路径：创建形态文档或扩展 covers。证据：新的映射。
4. 形态未变之处：写 doc_change: none 并附理由。证据：该声明。
5. 重建索引并运行链接检查。证据：输出。

## 借口与反驳

| 想法 | 反驳 |
|---|---|
| “代码改动是内部的，文档不受影响。” | 那就带着这个理由声明 doc_change: none。关卡需要的是声明，而不是假设。 |
| “我下个会话再更新文档。” | 下个会话不知道改了什么。现在更新，或者声明。 |
| “打个日期戳就够了。” | 没有内容核对的戳，只是带日期的漂移。 |

## 警示信号

- 被覆盖的路径变更了，既没有更新也没有声明。
- 文档更新了但没有 sources。
- 节点页面被手工重新生成。

## 验证

- 映射完整。
- 索引和链接检查通过。
- 声明都附有理由。

# strata.distill

## 개요

쓴 것이 아니라 배운 것을 업무 vault 에서 개인 코어로 옮깁니다. 업무 쪽에는 후보 기록을, 개인 쪽에는 원래 맥락 없이도 서는 패턴이나 가이드를 다시 써서 둡니다.

## 언제 쓰는가

세션 종료나 요청 시 재사용할 것이 나왔을 때 씁니다. 모든 세션에 후보가 있지는 않습니다. 이유가 적힌 '없음' 도 유효한 결과입니다.

## 절차

1. 프로젝트와 무관하게 문제와 판단으로 교훈을 이름 짓습니다. 증거: 한 문장.
2. 업무 vault 에 후보 기록을 씁니다. id, 출처 revision, 대상 노트 id, 상태. 증거: 기록.
3. 개인 코어 문서를 쓰거나 갱신합니다. 문제, 대안과 trade-off, 조건, 반례, 검증, 합성 예제. 증거: 문서.
4. guard(이름·도메인·경로·첨부)를 돌리고 결과를 직접 읽습니다. 증거: guard 출력.
5. 후보를 적용됨으로 표시합니다. 같은 id 로 다시 돌리면 갱신이지 중복이 아니어야 합니다.

## 합리화

| 생각 | 반박 |
|---|---|
| "이미 쓴 문서를 복사하면 된다." | 복사본은 회사 맥락을 가져갑니다. 일반적인 부분만 다시 쓰세요. |
| "guard 가 통과했으니 깨끗하다." | 문자열 검사는 이름을 잡지 형상을 잡지 못합니다. 외부인처럼 읽으세요. |
| "프로젝트 끝에 증류하겠다." | 교훈은 바랩니다. 배운 세션에서 증류하세요. |

## 적신호

- 회사 경로만을 출처로 둔 개인 코어 문서.
- 후보 id 하나에 문서 둘.
- 대상 id 가 없는 후보.

## 검증

- 후보 기록이 완전하다.
- 문서가 홀로 서고 guard 를 통과했으며 직접 읽었다.
- 재실행이 멱등이다.
